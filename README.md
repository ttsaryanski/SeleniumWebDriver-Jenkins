# Jenkins CI/CD Pipeline

⚠️ Learning project - Used for studying and testing:

- Jenkins Pipeline development
- CI/CD automation
- Parallel test execution

## Project Content

The project contains three test projects:

### TestProject1 - Unit Tests

- Calculator tests with various mathematical operations
- Web calculator application testing

### TestProject2 - Integration Tests

- Working with Web tables
- Product information data extraction
- CSV file generation

### TestProject3 - UI Tests

- Dropdown menu tests
- File content tests

## Jenkins Pipeline

The project includes a `Jenkinsfile` with defined stages:

1. **Install dependencies** - NuGet packages restoration
2. **Build** - Project compilation
3. **Run Tests** - Parallel execution of all test projects

Not intended for production use - educational purposes only.
